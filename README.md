My versions of some Vanilla Tweaks made for Faithful 32x32 (Minecraft)

## VisualWaxedCopperItems V3

Adds a gold wax border to copper items in the inventory. Available in **32x and 64x for Minecraft 1.17–26.3**, with one combined ZIP per resolution. Enable one above the matching [Faithful pack](https://faithfulpack.net/).

Copper golem statues retain their selected inventory pose and use the correct waxed textures, orientation and position in either hand and on shelves, including compatibility with 3D Items. Wax borders are rebuilt from original Faithful textures, with consistent item outlines and complete borders on lightning rods and statue model faces.

[Downloads](https://github.com/TQNL/TQNL-Faithful-Add-ons/releases/tag/VisualWaxedCopperItems-V3) · [Release notes and inventory previews](docs/visual-waxed-copper-v3/release-notes.md) · [Pack sources](visual-waxed-copper-v3/)

Copper items are included where the game provides them; this does not add later items to older Minecraft. The base pack supports clients before overlays, while later overlays select the appropriate item models. Minecraft 1.17–1.19.4 displays a version warning; its legacy item assets can still be enabled. See [compatibility and test scope](docs/visual-waxed-copper-v3/compatibility.md).

The previous [V2 release](https://github.com/TQNL/TQNL-Faithful-Add-ons/releases/tag/VisualWaxedCopperItems) and its [original icon](docs/visual-waxed-copper-v3/pack-V2-original.png) remain available. Other add-ons are unchanged.

Textures are adapted from Faithful 32x and 64x, following the Visual Waxed Copper (Items) tweak from [Vanilla Tweaks](https://vanillatweaks.net/). Credits, source references and applicable license files are included in each pack. The root `LICENSE` is retained for the older add-ons; V3's included license files identify the terms for its source textures.
