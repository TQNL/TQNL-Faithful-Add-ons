# VisualWaxedCopperItems V3

Copper-only resource pack sources for Minecraft **1.21.9–26.3**:

- [32x](32x/), for Faithful 32x.
- [64x](64x/), for Faithful 64x.

The contents of each directory match the corresponding release ZIP, including its resolution icon, overlays, credits, source provenance and licenses. The ZIP root is the contents of the resolution directory, not the directory itself.

[Download the ready-to-use ZIPs](https://github.com/TQNL/TQNL-Faithful-Add-ons/releases/tag/VisualWaxedCopperItems-V3) and enable one above the matching [Faithful pack](https://faithfulpack.net/). Placed copper blocks and live copper golems are unchanged.

[Release notes and inventory previews](../docs/visual-waxed-copper-v3/release-notes.md) · [Release ZIP SHA-256 hashes](../docs/visual-waxed-copper-v3/SHA256SUMS.txt)

Based on [Vanilla Tweaks](https://vanillatweaks.net/), using original Faithful copper textures with wax masks and statue repairs by TQNL. See each edition's `credits.txt`, `source-provenance.json` and license files for attribution and terms.
