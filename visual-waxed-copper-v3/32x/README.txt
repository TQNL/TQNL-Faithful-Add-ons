VisualWaxedCopperItems V3 - Faithful 32x
Minecraft 1.17 - 26.3

Enable this item-only add-on above a matching Faithful pack.
Pinned original Faithful artwork is used for the corresponding copper items.
Later copper items and item-definition schemas are selected through format overlays.
Modern 1.21.9-26.3 item textures and rendering resources match the reviewed V3 packs exactly.
Placed blocks, their textures, and live copper golems are unchanged.

Before Minecraft 1.20.2, clients only recognize one pack_format. The root uses format 15
(1.20/1.20.1), because modern range readers require this legacy marker to be at least 15.
The declared supported range still begins at format 7 / 1.17. Minecraft 1.17-1.19.4
therefore show an unavoidable compatibility warning and require manual enabling.
Those clients can still load the legacy item models; the warning is not a green compatibility claim.
See the release documentation for exact native, structural and visual test scope.
